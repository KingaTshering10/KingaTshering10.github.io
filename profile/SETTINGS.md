Two things live outside this website repo. Both are quick.

## 1. Publish the profile README

GitHub shows the README of a repo named **exactly the same as your username** at the top of
your profile page. It does not exist yet.

1. Create a **public** repo named `KingaTshering10` — https://github.com/new
   (GitHub will show a note: *"You found a secret! KingaTshering10/KingaTshering10 is a special
   repository..."* — that confirms you named it right.)
2. Tick **Add a README file**, then create.
3. Replace its contents with `profile/README.md` from this repo and commit.

Check the result at https://github.com/KingaTshering10
